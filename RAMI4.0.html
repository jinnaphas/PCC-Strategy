บทที่ 3 · RAMI 4.0 คืออะไร

Reference Architecture Model Industrie 4.0

แผนจำลองสถาปัตยกรรมอ้างอิงสำหรับ Industry 4.0 / Factory 4.0 ที่ช่วยออกแบบและพัฒนาโรงงานอัจฉริยะอย่างเป็นระบบ

เป็น Reference Modelหรือ “แผนจำลองสถาปัตยกรรมอ้างอิง (Blueprint)” สำหรับ Industry 4.0 / Factory 4.0
ไม่ใช่ Software, ERP, MES หรือแพลตฟอร์มแต่เป็นกรอบแนวคิดและโมเดลอ้างอิงที่ทุกระบบต้องวางตัวให้ตรง
ทำไมจึงสำคัญเป็นแผนที่ 3 มิติที่ใช้จัดวางเครื่องจักร ข้อมูล ระบบซอฟต์แวร์ และกระบวนการธุรกิจของโรงงาน ให้ทำงานร่วมกันได้อย่างเป็นระบบ มุ่งสู่ Smart Factory

I4.0 Componentระบุตัวได้ไม่ซ้ำ สื่อสารได้ เข้าร่วมระบบได้ทันที

เกณฑ์
  • ระบุตัวได้ไม่ซ้ำในระบบ
  • ระบบอ่านข้อมูลได้ อย่างน้อยสแกน QR/RFID
  • มี Administration Shell
ใช้ประโยชน์
  • ต่อแล้วใช้ได้ทันที ลดเวลาติดตั้งและทดสอบเดินเครื่อง
  • ข้อมูลตามตัวตลอดอายุ ตั้งแต่ผลิต ใช้งาน จนซ่อมบำรุง
  • ขายสินค้า + ฝาแฝดดิจิทัล บริการใหม่ที่คู่แข่งยังไม่มี
